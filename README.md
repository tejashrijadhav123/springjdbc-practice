# Spring JDBC CRUD Application

A simple Java-based CRUD application built using Spring JDBC and MySQL.
This project demonstrates how to perform database operations using Spring Framework's `JdbcTemplate` with clean DAO architecture and Dependency Injection.

## Features

* Insert student records
* Update existing student details
* Delete student records
* Fetch single student data
* Fetch all student records
* Spring Dependency Injection using XML and Java Configuration
* MySQL database integration
* DAO Layer implementation using Spring JDBC

## Technologies Used

* Java
* Spring Core
* Spring JDBC
* MySQL
* Maven
* Eclipse IDE

## CRUD Operations Implemented

* Insert Student
* Update Student
* Delete Student
* Get Student By ID
* Get All Students

## Learning Outcomes

This project helped in understanding:

* Spring IoC Container
* Dependency Injection
* Loose Coupling
* JdbcTemplate usage
* DAO Design Pattern
* Bean Configuration
* Integration of Spring with MySQL
